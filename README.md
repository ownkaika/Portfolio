## 我的實作方式

1. **觀察使用情境**：記下哪些資訊不好找、哪些操作重複或容易出錯。
2. **規劃功能與畫面**：整理主要操作、例外情況，以及應該優先完成的功能。
3. **實作與整合**：使用 ChatGPT、Codex、Google Antigravity 等 AI 工具協助理解、產生與修改程式，接觸 API、資料庫和雲端服務。
4. **自行檢查與改進**：在真實裝置或瀏覽器操作，確認資料有沒有保存、功能能否完成、錯誤時是否有清楚回饋。

我比較重視功能是否真正好用，而不是只讓畫面看起來完整。對電子支付、商場會員和停車服務的使用經驗，也讓我特別注意：重要資訊能不能在同一個畫面清楚呈現，操作能不能再少一步。
