# KPlayer 本機音樂

## 這是什麼作品？

KPlayer 是依照我在 iPhone 上的日常聆聽方式設計的本機音樂工具。我希望不用依賴線上串流曲庫，也能直覺地瀏覽手機裡的音樂並控制播放。

### 主要特色與使用情境

本機曲目瀏覽、播放、暫停與切換，專注於簡潔的 iOS 操作流程。

### 技術重點

本機音訊與播放控制的高層次規劃；未核對的底層播放框架不列為已證實技術。
