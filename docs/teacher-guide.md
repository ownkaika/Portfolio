# 王楷驊｜我平常在做的軟體作品

**給林傳筆老師：這一頁主要是介紹我在學校專題以外，平常自己做的東西。**

老師應該很熟悉我的課堂與專題情況，但以下 App、網站和自動化工具大多是我出於個人興趣、在課外自己規劃的，過去沒有特別公開介紹。希望透過這份簡介，讓老師先知道**每個作品是什麼、為什麼想做、實際解決了什麼問題**。

我最在意的不是使用了多少程式語言，而是能不能把「我想要一個這樣的功能」一步步做成真的能使用的產品。我會先規劃需求與操作方式，再用 ChatGPT、Codex 等 AI 工具協助開發，自己測試、找出問題、持續修改。不同專案有已實際使用、持續改善及仍在開發的階段。

## 最能代表我的六個作品

### 01．[TT 即時監視器｜Android](tt.md)

**為什麼做：**我喜歡看日本澀谷、新宿、淺草等地的即時街景，但直播分散在政府攝影機網站、YouTube 等不同平台，每次切換很麻煩。

**做成什麼：**我把不同直播來源整理成一個 App，加入日本街景、收藏等分類、直播來源管理和子母畫面（PiP），讓人可以在手機上持續觀看世界各地的即時影像。技術難點是不同串流來源的整合與播放器狀態管理。*持續改善中。*

### 02．[MIC AI 語音鍵盤｜Android / AI](mic.md)

**為什麼做：**我想在聊天、搜尋、記事的時候直接用說話輸入文字，不想開另一個錄音 App 再複製貼上。

**做成什麼：**我把 AI 語音辨識整合到 Android 輸入法裡，從鍵盤直接錄音、送出辨識，再把文字回填到正在輸入的地方；也設計複製、刪除等快捷操作。這個專案涉及 Android 輸入法、API 串接與大量實測除錯，**自動回填的穩定性仍在改善**。

### 03．[MultiPane 多畫面影音｜iOS / Android](multipane.md)

**為什麼做：**我希望在同一個手機畫面中同時看、比較或編排多張照片和影片，而不是每次只能開一個檔案。

**做成什麼：**設計能切換多格版型、調整區塊、分別操作照片與影片的影音工具，並規劃合成輸出。**iOS 版本已有實際使用經驗，Android 版正在移植**，因此也要考慮不同系統的介面與操作差異。

### 04．[Mac × Telegram 自動化｜Python](mac-auto.md)

**為什麼做：**有些影音下載、檔案整理工作經常重複，我希望即使人不在 Mac 前，也能從手機啟動。

**做成什麼：**以 Telegram 傳送遠端指令，讓 Mac 上的 Python 程式接收任務並執行自動化工作流程。這是我自己長期在本機使用的工具，讓我接觸訊息、腳本與作業系統功能整合。

### 05．[KaiBlog 個人部落格｜Web](kaiblog.md)

**為什麼做：**我不只想放文章，而是想自己決定整個網站怎麼運作，包括訪客看到什麼、後台如何管理內容。

**做成什麼：**嘗試建立文章編輯、分類、留言、媒體管理與後台，並串接資料庫、雲端部署和 AI 輔助功能。這個專案讓我練習的是一整套網站產品與資料流程，而不只是單一頁面。

### 06．[Photo 私人相簿｜Android](photo.md)

**為什麼做：**我希望把證件、作業、收據等照片跟一般手機相簿分開，能依自己的方式分類、排序與管理。

**做成什麼：**規劃獨立的私人媒體庫、照片匯入、分類、垃圾桶及可選隱私鎖等功能，也需要處理 Android 檔案授權與資料儲存。**部分功能仍在開發與實機驗證中**。

## 另外九個作品：各自解決一個小問題

- **[KAICODE 程式碼閱讀器](kaicode.md)**：在手機上閱讀 ZIP 專案、原始碼與 PDF，不必靠一般檔案管理器反覆打開檔案。
- **[EQ 地震工具](eq.md)**：把震央、地圖、所在地估算震度與 S 波倒數整理到易讀畫面；不能取代官方警報。
- **[AM 本機音樂播放器](am.md)**：為離線音樂、背景播放、記住進度與側邊快捷控制而製作。
- **[MP 浮動工具](mp.md)**：在使用其他 App 時直接顯示時間、日期和星期，並快速觸發功能。
- **[ST Telegram 快速分享](st.md)**：把 Android 的分享選單接到 Telegram「我的收藏」，減少切換 App 的步驟。
- **[Pp 桌面邊緣角色](pp.md)**：使用自己選的圖片做手機邊緣浮動角色，同時維持正常觸控操作。
- **[Lunar 農曆日曆](lunar.md)**：簡潔對照國曆、農曆，並探索和浮動視窗整合。
- **[KPlayer 本機音樂](kplayer.md)**：依照自己的 iPhone 聆聽習慣規劃本機音樂操作介面。
- **[AI 飲食分析學校專題](food.md)**：拍攝餐點後以 AI 協助辨識食物並呈現營養估算；**這一項是學校專題，不是上述課外個人作品**。

## 如果老師只看一段：我的學習方式

我通常是先遇到一個真實需求，自己決定「想讓產品怎麼用」，再把功能拆開實作，串接需要的 API 或系統功能，最後在手機或電腦實際使用並持續修正。AI 工具協助我寫程式與排查問題，但產品需求、操作設計、測試回饋與取捨是我反覆參與的部分。

**我希望往資訊管理、資訊系統規劃、AI 應用及專案整合發展。**這份作品集想呈現的是學習動機與實作經驗，並不是宣稱所有技術都已精通、所有功能都驗收完成。
