# 給林傳筆老師的作品與學習背景簡介｜王楷驊

> **用途**：協助老師用幾分鐘理解學生的修課、專題及自主開發經歷，方便老師依自身觀察評估是否推薦。這是**學生提供的事實整理與作品導覽**，不是請老師照抄的推薦信，也不代表老師已實際驗證每個個人專案。

## 一、師生關係與學習背景

- **學生**：王楷驊，朝陽科技大學資訊與通訊系。
- **老師**：林傳筆副教授，朝陽科技大學資訊與通訊系。
- **修課關係**：曾修習林老師教授的「微積分（二）」，成績為八十餘分。
- **專題指導**：林老師同時擔任專題指導老師，從上一學期至本學期，**目前為第二個學期**。
- **升學方向**：希望報考資訊管理、資訊科技應用或相關碩士班，進一步學習系統規劃、資料應用、AI 整合及專案管理。

對老師而言，**實際授課與專題指導的觀察最有說服力**；以下課外作品可以補充理解學生的興趣、學習方式與實作範圍。

## 二、學校專題：AI 飲食分析

[查看專題簡介、應用流程與技術架構](food.md)

目標是讓一般使用者提供餐點照片後，透過 AI 協助辨識食物，將熱量與營養估算資訊整理成較容易閱讀的結果。這個題目不只是模型辨識，也涉及**使用者需求、影像輸入、API 整合、結果呈現及誤差限制**。

**供老師自行判斷的觀察重點**：學生在專題中的實際分工、提出想法的能力、進度執行、討論溝通、問題解決與修改情形。學生不代替老師對這些表現下結論。

## 四、我如何完成這些作品

通常從自己的真實需求或使用不便開始：**發現問題 → 規劃功能與介面 → 使用 ChatGPT／Codex 等 AI 工具輔助開發 → 串接 API 或系統功能 → 實機測試、發現錯誤、持續修改**。

這並不是宣稱我能不依賴工具完成所有程式碼，或已精通每一種技術。比較能反映我的特點，是**願意把需求具體化、整合不同工具、追蹤問題並持續改善產品體驗**。部分專案仍在開發中，不能把架構示意圖當成通過完整驗收的證明。

## 五、供老師撰寫推薦信時參考

如果老師願意協助推薦，建議以**老師真正親自觀察到的課程與專題表現**為主，例如學習態度、參與情形、分工、討論與進度；再依本頁的作品介紹，補充學生課外的自主學習興趣與資訊系統實作方向。

不需要宣稱老師親自指導過上面每個個人 App，也不需誇大數學排名、技術熟練度或成果完成度。**老師可依實際了解自由取捨、調整或不採用以上內容。**
