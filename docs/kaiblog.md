## 這是什麼作品？

KaiBlog 是我自主規劃的個人部落格與內容管理網站。我希望不只發布文章，也能自己設計文章編輯、分類、媒體、留言與管理後台，藉此接觸完整的網站產品流程。

### 主要特色與使用情境

讀者可以瀏覽文章；管理者能處理內容、資料與權限，並探索 AI 協助寫作及內容整理。

### 技術重點

React、TypeScript 前端介面與 Supabase 資料管理、Vercel 部署及 AI API 整合。
